## Technischer Scope

CryoOmega ULTRA stellt eine Gateway-zentrierte Laufzeit und Client-Oberflächen für Agents, Skills und Plugins bereit. Ergänzend enthält das Repository Browser-Extension-Code, Evaluationswerkzeuge, Betriebsdokumentation und eine Docs-as-Code-Wikiquelle.

# Getting Started

This section gets a new developer from a fresh checkout to a working CLI, TUI, Web IDE and gateway session.

## Quick path

1. Clone the repository.
2. Run `./bin/omega doctor`.
3. Start `./bin/omega chat` for TUI access.
4. Start `./bin/omega ide` for the Web IDE.
5. Use `./bin/omega gateway status|log` to inspect the engine.

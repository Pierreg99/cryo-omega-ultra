## Project-created assets

Repository-created SVG/GIF/PNG assets are documentation or interface assets unless a file states otherwise. Keep them local and versioned so README rendering does not depend on an external image host.

## Third-party assets

Do not add third-party graphics, fonts, logos, trademarks, or code without recording provenance and license compatibility. Prefer original project assets or permissively licensed material with documented attribution.

## Animated GIF policy

The repository demo GIFs under `assets/demos/` are illustrative UI/architecture animations. They must not be described as live telemetry, test evidence, benchmark results, or security proof.

## Asset checklist

- [ ] Source/provenance is known.
- [ ] License is compatible with repository distribution.
- [ ] Attribution is recorded when required.
- [ ] No secrets or private data are embedded.
- [ ] README references use repository-local paths where possible.
- [ ] Large binaries are justified and kept small enough for normal Git operations.
